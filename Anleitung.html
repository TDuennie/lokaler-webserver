Anleitung

Webserver im Drive

Ein Ordner, ein Doppelklick, und die eigenen Seiten sind im Browser da – mit PHP und SQLite. Es muss nichts installiert werden, und es geht nichts ins Internet.

1

Was in den Ordner gehört

Der Ordner darf überall liegen – auf dem Schreibtisch, auf einem Stick oder im Drive. Der Server sucht alles im eigenen Ordner, deshalb ist der Pfad egal. Wird der Ordner verschoben oder kopiert, läuft er weiter.

Die node.exe wird nicht installiert

Sie liegt einfach im Ordner mit und wird von dort verwendet. Fehlt sie, sagt die Startdatei Bescheid und nennt die Adresse zum Herunterladen.

3

Die eigenen Seiten ablegen

Alles, was in den Ordner www kommt, ist sofort im Browser da. Der Pfad im Ordner ist die Adresse:

www\index.html → localhost:8080/
www\preise.html → localhost:8080/preise.html
www\bilder\logo.png → localhost:8080/bilder/logo.png
www\shop\index.php → localhost:8080/shop/

Neben HTML gehen auch CSS, JavaScript, Bilder, PDF, Video und Audio. Videos lassen sich vorspulen, ohne dass die ganze Datei geladen wird.

Ordner ohne Startseite

Liegt in einem Ordner keine index.html, zeigt der Server den Inhalt als Liste – praktisch, um schnell an eine einzelne Datei zu kommen:

Änderungen sind sofort sichtbar

Der Server lässt den Browser nichts zwischenspeichern. Datei ändern, speichern, neu laden – der neue Stand ist da.

4

Port und andere Einstellungen

Beim ersten Start entsteht die Datei einstellungen.txt. Sie lässt sich mit jedem Texteditor öffnen. Nach einer Änderung den Server einmal neu starten.

EinstellungBedeutung
port = 8080 Auf welchem Port der Server läuft. Ist der Port belegt, nimmt der Server von selbst den nächsten freien und sagt es beim Start.
ordner = www Welcher Ordner im Browser gezeigt wird.
browser = ja Ob sich der Browser beim Start öffnen soll.
netzwerk = nein Bei ja können auch Handy, Tablet oder die Kollegen im selben Netz die Seiten aufrufen. Die Adresse dafür steht dann beim Start dabei.
ordnerliste = ja Ob der Ordnerinhalt gezeigt wird, wenn keine index.html da ist.

Adresse ohne Portnummer

Wer statt localhost:8080 lieber nur localhost tippen möchte, trägt Port 80 ein:

einstellungen.txt
# Auf welchem Port der Server laeuft.
port = 80
Port 80 ist oft schon vergeben

Auf vielen Rechnern benutzt ihn bereits ein anderes Programm – häufig IIS oder Skype. Am Mac und unter Linux braucht Port 80 zusätzlich besondere Rechte. Klappt es nicht, schreibt der Server beim Start genau hin, woran es liegt und was zu tun ist. Im Zweifel einfach bei 8080 bleiben.

5

PHP und SQLite einschalten

Für HTML, Bilder und CSS ist nichts weiter nötig. Erst PHP-Seiten brauchen ein PHP im Ordner. Das sind drei Handgriffe:

  • Auf windows.php.net/download die Fassung VS17 x64 Non Thread Safe als ZIP herunterladen.
  • Entpacken und den entpackten Ordner php nennen – direkt neben server.js. Es muss also php\php-cgi.exe geben.
  • Den Server neu starten.
Die php.ini legt der Server selbst an

Ein frisch entpacktes PHP bringt keine Einstellungsdatei mit – dann wäre alles abgeschaltet, auch SQLite. Fehlt sie, schreibt der Server eine passende hinein. Eine bereits vorhandene php.ini bleibt unangetastet.

Ob es geklappt hat, zeigt die mitgelieferte Seite localhost:8080/test.php. Sie legt gleich eine kleine Datenbank an und schreibt bei jedem Aufruf eine Zeile hinein:

Datenbanken richtig ablegen

SQLite braucht keine Installation – eine Datenbank ist einfach eine Datei. Sie gehört aber nicht in den Ordner www, sondern daneben, zum Beispiel in einen Ordner daten:

PHP
$db = new PDO("sqlite:" . __DIR__ . "/../daten/meine.sqlite");
Datenbanken sind vor dem Browser geschützt

Dateien wie .sqlite, .db und .env liefert der Server grundsätzlich nicht aus – auch dann nicht, wenn sie versehentlich in www landen. In der Ordnerliste tauchen sie ebenfalls nicht auf. PHP kann sie ganz normal öffnen.

6

Beenden

Doppelklick auf Webserver beenden.cmd. Wurde er mit Fenster gestartet, genügt auch, dieses Fenster zu schließen.

Den Server einfach laufen zu lassen, ist ebenso in Ordnung – er braucht im Leerlauf so gut wie nichts und ist beim Herunterfahren des Rechners weg.

7

Wenn etwas nicht klappt

Im Zweifel Webserver mit Fenster starten.cmd nehmen – dort steht, was los ist.

Meldung oder VerhaltenDas hilft
Node.js wurde nicht gefunden Die node.exe fehlt im Ordner. Sie steckt in der ZIP-Datei „Windows Binary (.zip)“ auf nodejs.org im Ordner node-vXX-win-x64.
PHP ist nicht eingerichtet Der Ordner php fehlt – siehe Schritt 5.
Es kommt eine Dateiliste statt der Seite In dem Ordner fehlt eine index.html.
Nicht gefunden Die Datei liegt nicht in www, oder der Name ist anders geschrieben. Groß- und Kleinschreibung kann eine Rolle spielen.
Port 80 lässt sich nicht verwenden Er ist belegt oder braucht besondere Rechte. In einstellungen.txt wieder 8080 eintragen.
Änderungen sind nicht zu sehen Der Server sendet immer den neuesten Stand. Hält der Browser trotzdem etwas fest, hilft Strg + F5.
Der Browser geht nicht auf Die Adresse aus dem Fenster von Hand eintippen, meist localhost:8080.
Es geht nichts nach draußen

Der Server ist nur auf dem eigenen Rechner erreichbar. Erst wenn in den Einstellungen netzwerk = ja steht, kommen andere Geräte im selben Netz heran – und dann weist der Server beim Start ausdrücklich darauf hin.
