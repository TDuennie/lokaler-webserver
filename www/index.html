Es funktioniert

Diese Seite liegt im Ordner www. Alles, was dort hineinkommt, ist sofort im Browser erreichbar.

  • Eigene Seiten einfach in www ablegen
  • Diese Datei index.html ersetzen oder ändern
  • test.php aufrufen – zeigt, ob PHP und SQLite bereitstehen
  • Port und Ordner stehen in einstellungen.txt

Beim Neuladen kommt immer der aktuelle Stand – der Server schaltet das Zwischenspeichern im Browser bewusst ab.

Zum Beenden das Fenster schließen oder Webserver beenden.cmd aufrufen.
